# @utexo/rgb-lightning-node-bare — CLAUDE.md

## Project overview

`@utexo/rgb-lightning-node-bare` is a Bare-runtime native addon that wraps the C FFI of `rgb-lightning-node` (RLN) — the Lightning + RGB daemon built on LDK and `rgb-lib`. Its only consumer is `@utexo/wdk-rgb-lightning`, the WDK module that runs inside a Bare worklet on mobile (via `react-native-bare-kit`) or as a desktop subprocess.

The package mirrors `@utexo/rgb-lib-bare` in build philosophy: a pre-compiled Rust static library (`librlncffi.a`) is linked statically into a single self-contained `.bare` addon using `cmake-bare`. The JS surface (`SdkNode`, `NativeExternalSigner`) is identical to the Node.js sibling (`@utexo/rgb-lightning-node-nodejs`), so WDK can select the right binding at module-load time without touching business logic.

## Stack

| Layer | Technology |
|---|---|
| Addon format | Bare (`.bare` addon, not `.node`) |
| C/C++ binding | `binding.cc` — Bare's `<js.h>` / `<bare.h>` API (no N-API/napi-rs) |
| Build system | `cmake-bare` + `cmake-npm` (CMake 3.25+) |
| Rust library | `librlncffi.a` — static lib produced by `cargo rustc --crate-type staticlib` |
| Rust toolchain | Pinned in `utexoNativeOverlay.rustToolchain` (currently `1.94.0`) |
| Android NDK | Pinned version `27.1.12297006`, API level 29, via `cargo-ndk` `4.1.2` |
| cbindgen header | `rln.h` — generated by cbindgen, committed, defines `CResult`, `CResultString`, `COpaqueStruct`, and all `rln_*` symbols |
| JS facade | `index.js` (CommonJS, no transpiler), TypeScript declarations in `index.d.ts` |
| Test runtime | `bare-runtime` (`1.30.3`) for the integration smoke test |
| Package manager | npm (`npm ci` always) |

## Build and test

### Install (consumer)

```sh
npm ci
# Packed postinstall hydrates all three required exact-version data dependencies and verifies all seven targets.
# Missing or inconsistent distributed artifacts fail without a source-build fallback.
# To skip native artifacts for JS-only CI:
RLN_BARE_JS_ONLY_INSTALL=1 npm ci
```

### Build from source (maintainer)

```sh
# Set the normal Rust/Cargo bin path and full Xcode environment first.
# Bootstrap this source checkout and its three local native data workspaces without lifecycle execution.
npm ci --ignore-scripts
# The public manifest selects the exact source, locked graph and adapter.
# Private upstream BFA dependencies require scoped source-read access.
RLN_BARE_TARGETS=darwin-arm64 npm run prepare-native
RLN_BARE_TARGETS=ios-arm64 npm run prepare-native
RLN_BARE_TARGETS=android-arm64 npm run prepare-native
# Substitute any exact configured target; no group alias or legacy download.
# After preparing/importing all seven release targets, stage every data workspace:
npm run stage:payloads
npm run check:distribution
```

### Type-check and tests

```sh
npm run check:types          # tsc --noEmit --strict --skipLibCheck index.d.ts
npm run test:installer       # unit tests for installer scripts (Node.js)
python3 -B scripts/test-distribution-archives.py # archive admission rejection tests
npm test                     # installer tests + bare-runtime smoke test
```

## Code conventions

### C++ (`binding.cc`)

- **Bare API only**: `<bare.h>` + `<js.h>`. Never use N-API or node-addon-api.
- **Helper macros** for C-FFI function shapes:
  - `FN_NODE(NAME, RLN_FN)` — `(node) → CResultString`
  - `FN_NODE_STR(NAME, RLN_FN)` — `(node, str) → CResultString`
  - `FN_NODE_JSON(NAME, RLN_FN)` — alias for `FN_NODE_STR`; signals JSON input
  - `FN_NODE_BOOL(NAME, RLN_FN)` — `(node, bool) → CResultString`
  - `FN_NODE_SIGNER(NAME, RLN_FN)` — `(node, signer) → CResultString`
- **Opaque handles**: `SdkNodeRef` and `SignerRef` wrap `COpaqueStruct`. Both carry a `freed` guard. `SdkNodeRef` additionally has `shutdown_attempted` and `teardown_registered`.
- **Memory ownership**: every `char *` from `js_to_cstring` must be `free()`-d immediately after the C-FFI call. Every `CResultString.inner` must be `rln_free_string()`-d after use.
- **Error handling**: `handle_result_string` throws a JS Error with the native message on `Err`.

### JavaScript (`index.js`)

- CommonJS, no bundler, no transpiler.
- All C-FFI calls accept/return JSON strings; `index.js` owns `lossless JSON serialization and parsing through `json-boundary.js`.
- Failed `shutdown()` preserves retryable native handles. Successful shutdown/disposal must not double-free handles. Follow the current lifecycle contract tests.
- `NativeExternalSigner.create()` validates `seedHex.length === 64` before crossing the FFI boundary.

### TypeScript (`index.d.ts`)

- Monetary amounts typed as `DecimalString` (`\`${bigint}\``) to stay within JS safe-integer range.
- `JsonObject`, `JsonValue`, `JsonRequest` are escape hatches for unfully-typed methods.

### Scripts

- `native-overlay.js` is the security boundary: validates patch SHA-256, symbol lists, artifact provenance. Never relax these checks.
- `LIBRARY_SYMBOLS` and `PREBUILD_SYMBOLS` are the authoritative symbol contract. Add new symbols here when adding C-FFI methods.

## Code review focus areas

### Security and supply chain

- **Patch integrity**: `utexoNativeOverlay.patchSha256` must match the actual patch file on every PR touching `patches/` or `package.json`.
- **Symbol contract**: new `rln_*` symbols in `binding.cc` must be added to `LIBRARY_SYMBOLS`/`PREBUILD_SYMBOLS` in `native-overlay.js`.
- **Seed safety**: `seedHex` must never be logged, serialized to disk, or passed to non-FFI callees. The 64-char hex validation is the first guard — do not remove it.
- **Artifact provenance**: `.utexo-native-overlay.json` records per-target SHA-256. CI must not skip provenance writing.
- **Repository allowlist**: `readOverlayConfig` enforces `utexoNativeOverlay.repository` exactly. Do not widen this check.

### Memory safety (`binding.cc`)

- Every `js_to_cstring` result must be `free()`-d before the function returns, including on the error path.
- `handle_result_string` always calls `rln_free_string(res.inner)` — never skip this.
- `shutdown_and_free_sdk_node` sets `freed = true` before calling `free_sdk_node`. Any change to this sequence risks a double-free.
- `shutdown_attempted` is set **before** entering native code to survive a panic.

### C-FFI shape consistency

- Use `FN_NODE_JSON` for methods that take a JSON request body; `FN_NODE_STR` for single string args.
- Every new C-FFI function in `binding.cc` must have a JS wrapper in `index.js` and a TS declaration in `index.d.ts`.
- Add new critical methods to the smoke test's method-existence check in `test.js`.

### Build and CI

- Android `.bare` addons must be stripped with `llvm-strip --strip-debug` from the pinned NDK toolchain. macOS `strip` corrupts ELF archives.
- `RLN_BARE_JS_ONLY_INSTALL=1` must bypass all native artifact steps but must not create fake artifact files.
- `utexoNativeOverlay.ref` and `utexoNativeOverlay.commit` must be updated together when the upstream RLN tag changes.

## Distribution changes

Keep the wrapper Darwin-only and all three companions required at the exact owner
version, without platform filters or executable metadata. The Android ARM payload
contains `android-arm` and `android-arm64`; Android x64 is separate. Validate every
payload and destination before any copy, verify staged bytes before replacement,
and preserve retry after interrupted assembly. The archive gate checks all four
packages with 128 MiB budgets for new uploads. The published iOS beta.4 archive is
immutable (146,197,231 bytes, frozen SRI in the archive verifier) and must never be
republished or changed. `stage:ios-payload` only stages iOS; release preparation
uses `stage:payloads`. Package source commits, publication workflow commits and
original native build provenance are separate evidence.
