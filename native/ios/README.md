# Bare iOS prebuild payloads

This required data package contains the three original, provenance-verified iOS addons for the exact matching `@utexo/rgb-lightning-node-bare` version. It has no lifecycle scripts, JavaScript entry point, platform filter or CPU filter. Install the parent package; its postinstall validates this payload before restoring all seven canonical addon paths.

The compiled native bytes are unchanged from their qualified CI artifacts. Package assembly and native compilation have distinct source identities.
